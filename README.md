# Primary care mortality gap — reproducible decision-analytic models

Transparent, deterministic models for two independent studies:

1. **AI-effectiveness threshold** — the per-patient mortality effect and reach a clinical AI agent
   would need to close the residual primary care mortality gap, with a three-bundle taxonomy of
   clinical AI (disease-specific, generalist consumer, provider-facing) and an
   extract-replicate-transmit validation.
2. **Combined-intervention comparative risk assessment** — the fraction of the mortality gap that a
   package of established structural interventions closes.

This repository contains **code and public inputs only**. It contains no patient-level or protected
health information and no data files; every input is public (CDC WONDER, NHANES, published effect
sizes) or a stated assumption in `inputs.json`. All model outputs are regenerated by running the
code. Manuscripts and figures are maintained separately and are not part of this repository.

## Layout

```
ai-effectiveness-threshold/code/        threshold_model.py, validate_ai_bundles.py,
                                        validate_ai_transmission.py, inputs.json
combined-intervention-simulation/code/  portfolio_model.py, validate_backtest.py, inputs.json
make_figures.py                         all figures (deterministic, from regenerated outputs)
verification/consistency_check.py       asserts every manuscript number == regenerated model output
build_docx.sh                           assembles submission .docx (requires local manuscripts)
```

## Reproduce

```
export REDERIVE_TS=$(date -u +%Y-%m-%dT%H:%M:%SZ)
python3 combined-intervention-simulation/code/portfolio_model.py     # structural closure + PSA
python3 ai-effectiveness-threshold/code/threshold_model.py           # required-HR threshold + sensitivity
python3 ai-effectiveness-threshold/code/validate_ai_bundles.py       # three mechanism bundles
python3 ai-effectiveness-threshold/code/validate_ai_transmission.py  # extract-replicate-transmit
python3 make_figures.py
python3 verification/consistency_check.py
```

All models are deterministic under a fixed seed (`20260720`); re-running produces identical outputs,
written to a local `results/` directory (git-ignored). Each run also writes a provenance record
(input hash, seed, software versions).

Requirements: Python 3, `numpy`, `pandas`, `matplotlib`.
